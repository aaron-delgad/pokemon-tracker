# Arquitectura
# Usamos una Arquitectura orientada a funcionalidades
# Separamos la capa de presentación de la lógica de negocios y el acceso a datos
# Manejo de estado con angular signals
# Logramos persistencia local con @capacitor/preferences

# Instrucciones de instalacion
# git clone https://github.com/aaron-delgad/pokemon-tracker.git
# npm install
# ejecutar: ionic serve --lab

# Instruccion para generar apk
# npm run build
# npx cap sync android
# npm run build:android
# npx cap open android
